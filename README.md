# Library Pro — React Dashboard UI

A responsive React dashboard UI for a Diploma class project.

## Requirements
- Node.js 18.18+ (Node.js 20 LTS recommended)
- npm

## Run locally
1. Extract this ZIP.
2. Open the extracted folder in VS Code.
3. Open Terminal in this folder.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local URL printed by Vite (usually http://localhost:5173).

## Production build
```bash
npm run build
npm run preview
```

## Included
- Responsive dashboard
- Sidebar navigation states
- Demo statistics and transactions
- Borrowing activity chart and category chart
- Search filtering for the popular-books section
- Bengali/English interface toggle
- Light/dark theme toggle

## Notes
This is a frontend UI prototype using sample data. Navigation items currently change the selected page heading; other modules will be built in subsequent steps. No backend or real database is connected yet.
